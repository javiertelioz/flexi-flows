# Advanced Hooks Monitoring Example

Demuestra observabilidad completa con hooks, métricas y logging:

## 🎯 Características:
- Hooks personalizados en cada etapa
- Métricas de rendimiento
- Logging estructurado
- Manejo avanzado de errores

## 📋 Flujo:
```
E-commerce Order → [Pre/Post Hooks] → Payment → Inventory → Shipping → Notifications
```

## 🚀 Ejecutar:
```bash
cd examples/advanced_hooks_monitoring
go run main.go --mode=config --order-id=12345
```
